# Workspace Guidelines

## Active Skills & Rules
- **Ponytail (`ponytail`) is ALWAYS ACTIVE**:
  - Always seek the simplest, most minimal solution that actually works (YAGNI).
  - Prefer standard libraries and native web platform features over external dependencies or custom wheels.
  - Write concise, direct code first with minimal unrequested prose.
  - Always understand the root cause before implementing the smallest correct fix.
  - Maintain safety, accessibility, and validation.

- **Design Specification (`DESIGN.md`) is ALWAYS ACTIVE**:
  - **Strict Prohibition**: No blue or purple gradient designs anywhere in the project (no blue/purple linear/radial gradients, glows, or haze).
  - **Style Mandate**: Strict **Minimalist Flat Geometric Style** (极简平面几何风格) — solid color fills, sharp geometric lines, crisp borders (0-4px radius), high contrast, snappy transitions.

- **Git & Deployment Rule**:
  - **Strict Prohibition on Unrequested Pushes**: Never automatically or proactively push (`git push`) changes to the GitHub remote repository unless the user explicitly requests to publish or push to GitHub.
